# バズレシピ帳

InstagramやX（旧Twitter）などのSNSで見つけたレシピを、**写真（スクリーンショット）をアップロードするだけ**で保存して、あとから一覧で見返せるWebアプリです。

スマホのホーム画面に追加すればアプリのように使えます。サーバーは不要で、データはその端末のブラウザ内に保存されます。

## できること

| 機能 | 内容 |
| --- | --- |
| 写真で登録 | スクショを選ぶだけで保存。複数枚OK・表紙の入れ替えもできる。料理名が空なら「2026/11/1 のレシピ」のように自動で名前をつける |
| 詳細の記録（任意） | 料理名・元の投稿URL・投稿者・タグ・材料・作り方・メモ |
| SNSの自動判定 | URLを貼るとInstagram / X / TikTok / YouTube を自動で判定 |
| 一覧・検索 | サムネイル一覧、キーワード検索（料理名・材料・タグ・メモ）、SNS別・タグ別・お気に入り・「作った／まだ」で絞り込み、並べ替え |
| 料理中に便利 | 材料はチェックリスト、作り方は番号付き。写真はタップで拡大 |
| 作った記録 | 「作った！」ボタンで回数と最終日を記録（「よく作る順」で並べ替え可） |
| 文字読み取り（OCR） | 画像内の材料や作り方を読み取り、ボタンで各欄に追加（初回のみネット接続が必要） |
| 共有から登録 | Androidでアプリとしてインストールすると、ギャラリーやSNSアプリの「共有」からこのアプリへ写真やURLを直接送れる |
| バックアップ | 全データ（写真込み）をJSONファイルに書き出し・読み込み。機種変更時の引っ越しにも使える |
| オフライン | 一度開けば、電波がなくても閲覧・登録できる |

## 使い方

1. 気になるレシピ投稿をスクリーンショットする
2. アプリの「＋登録」から写真を選んで「保存する」
3. 必要に応じて料理名やタグ、元の投稿のURLを追加

## 公開方法（GitHub Pages）

ビルドは不要です。静的ファイルをそのまま公開します。

1. このブランチを `main` にマージする
2. GitHubのリポジトリで **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける
5. スマホで開いてホーム画面に追加する
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：メニュー →「アプリをインストール」

※ Service Worker（オフライン対応・共有受け取り）は HTTPS か `localhost` でないと動きません。

## 手元で動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## データについての注意

- データは**端末のブラウザ内（IndexedDB）にだけ**保存され、外部には送信されません（OCR用ライブラリの読み込みだけはCDNに接続します）。
- そのため、別の端末とは自動で同期されません。移すときは「設定・バックアップ」から書き出し→読み込みしてください。
- ブラウザのデータを消すとレシピも消えます。設定画面の「データを消えにくくする」を押す、ホーム画面に追加して使う、ときどきバックアップする、のいずれかをおすすめします。
- 写真は保存時に自動で縮小（長辺2000px・JPEG）して容量を節約しています。
- iPhoneのHEIC写真はブラウザによって読み込めない場合があります。スクリーンショット（PNG）なら問題ありません。

## ファイル構成

```
index.html            画面の土台
styles.css            デザイン（ライト／ダークモード対応）
js/app.js             画面表示・操作（一覧／登録・編集／詳細／設定）
js/db.js              IndexedDB への保存
js/image.js           写真の縮小・サムネイル作成
js/ocr.js             文字読み取り（Tesseract.js を必要なときだけ読み込む）
sw.js                 Service Worker（オフライン対応・共有の受け取り）
manifest.webmanifest  PWA設定（ホーム画面アイコン・共有ターゲット）
icons/                アプリアイコン
```
