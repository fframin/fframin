# バズレシピ帳

InstagramやX（旧Twitter）などのSNSで見つけたレシピを、**写真（スクリーンショット）をアップロードするだけ**で保存して、あとから一覧で見返せるWebアプリです。

スマホのホーム画面に追加すればアプリのように使えます。サーバーは不要で、データはその端末のブラウザ内に保存されます。

## できること

| 機能 | 内容 |
| --- | --- |
| 写真で登録 | スクショを選ぶだけで保存。複数枚OK・表紙の入れ替えもできる。料理名が空なら「2026/11/1 のレシピ」のように自動で名前をつける |
| 投稿文で登録 | InstagramやXの投稿文（キャプション）を貼り付けると、料理名・何人分・材料・作り方・タグ・URLに自動で振り分ける |
| 文章 → 画像 | 写真がないレシピは、料理名と材料からカード画像を自動で作って一覧に表示 |
| 写真 → 文章（AI） | ClaudeのAPIキーを設定すると、スクショや料理写真から料理名・材料・作り方を書き起こす。レシピが書かれていない料理写真からも作り方を推測できる |
| URLから取り込み | 取り込みサーバーを設置すると、Instagram / X / TikTok / YouTube の投稿URLから写真と文章をまとめて取り込める |
| 分量の計算 | 人数の＋−、×1/2〜×3のボタン、または材料の分量をタップして手元の量（例：鶏むね肉 300g → 450g）を入れると、全部の材料と作り方の中の分量（水200ml など）を同じ割合で計算し直す。「3分」「600W」「1cm幅」などは変えない |
| 詳細の記録（任意） | 料理名・元の投稿URL・投稿者・タグ・材料・作り方・メモ |
| SNSの自動判定 | URLを貼るとInstagram / X / TikTok / YouTube を自動で判定 |
| 一覧・検索 | サムネイル一覧、キーワード検索（料理名・材料・タグ・メモ）、SNS別・タグ別・お気に入り・「作った／まだ」で絞り込み、並べ替え |
| 料理中に便利 | 材料はチェックリスト、作り方は番号付き。写真はタップで拡大 |
| 作った記録 | 「作った！」ボタンで回数と最終日を記録（「よく作る順」で並べ替え可） |
| 文字読み取り（OCR） | 画像内の文字を読み取り、自動で各欄に振り分け（APIキー不要・初回のみネット接続が必要） |
| 共有から登録 | Androidでアプリとしてインストールすると、ギャラリーやSNSアプリの「共有」からこのアプリへ写真やURLを直接送れる |
| バックアップ | 全データ（写真込み）をJSONファイルに書き出し・読み込み。機種変更時の引っ越しにも使える |
| オフライン | 一度開けば、電波がなくても閲覧・登録できる |

## 使い方

1. 気になるレシピ投稿をスクリーンショットする（または投稿文をコピーする）
2. アプリの「＋登録」から写真を選ぶ／投稿文を貼り付けて「保存する」
3. 必要に応じて「✨ AIでレシピを書き起こす」「🔍 写真の文字を読み取る」で材料や作り方を入れる
4. 作るときは詳細画面で人数や分量を変えると、材料が自動で計算し直される

## AIで書き起こし（任意）

AnthropicのClaude APIを使います。

1. [Claude Console](https://console.anthropic.com/settings/keys) でAPIキーを発行する（使いすぎ防止に月の上限額も設定しておくと安心）
2. アプリの「設定・バックアップ」→「AIで書き起こし」にキーを貼り付けて保存
3. 登録画面で写真を選ぶか投稿文を貼り付け、「✨ AIでレシピを書き起こす」を押す

- 使用モデルは Claude Opus 5.5。使った分だけ料金がかかります。
- キーはその端末のブラウザ内にだけ保存され、Anthropic のAPIを呼ぶときにだけ使われます。共用の端末では登録しないでください。

## SNS取り込みサーバー（任意）

InstagramやXの投稿はブラウザから直接読み込めない（CORS・ログイン制限）ため、URLから写真と文章を取り込むには中継サーバーが必要です。`server/import-worker.js` を Cloudflare Workers（無料枠あり）に置きます。

1. [Cloudflare](https://dash.cloudflare.com/) にログインし、「Workers & Pages」→「作成」→「Worker」で新しいWorkerを作る（名前は例：`buzz-import`）
2. 「コードを編集」を開き、`server/import-worker.js` の中身をすべて貼り付けて「デプロイ」
3. Workerの「設定」→「変数とシークレット」で `TOKEN` に好きな合言葉を設定（他人に使われないようにするため。推奨）
4. 表示されたURL（`https://buzz-import.xxxx.workers.dev`）と合言葉を、アプリの「設定・バックアップ」→「SNS取り込みサーバー」に保存
5. 登録画面でURLを入れて「📥 このURLから写真と文章を取り込む」

対応状況：

| SNS | 取り込み方 | 注意 |
| --- | --- | --- |
| Instagram | 投稿ページのOGP（表紙画像・キャプション） | 1枚目の画像だけ。非公開投稿や、Instagram側の制限で取れない場合あり |
| X | FxTwitter API（`api.fxtwitter.com`）経由で本文と画像 | 外部の無料サービスに依存 |
| TikTok / YouTube | 公式の oEmbed（タイトル・サムネイル） | 動画そのものは取り込まない |
| その他のサイト | OGP（タイトル・説明・画像） | |

※ SNS側の仕様変更で取れなくなることがあります。取れないときは、スクショか投稿文のコピーで登録してください。取り込んだ内容は個人で見返す範囲で使ってください。

## 公開方法（GitHub Pages）

ビルドは不要です。静的ファイルをそのまま公開します。

1. このブランチを `main` にマージする
2. GitHubのリポジトリで **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける
5. スマホで開いてホーム画面に追加する
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：メニュー →「アプリをインストール」

※ Service Worker（オフライン対応・共有受け取り）は HTTPS か `localhost` でないと動きません。

## 手元で動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## データについての注意

- データは**端末のブラウザ内（IndexedDB）にだけ**保存されます。外部に送られるのは、AI書き起こしを使ったときの写真・文章（Anthropicへ）と、URL取り込みを使ったときの投稿URL（自分の取り込みサーバーへ）だけです。OCR・AI用のライブラリはCDNから読み込みます。
- そのため、別の端末とは自動で同期されません。移すときは「設定・バックアップ」から書き出し→読み込みしてください。
- ブラウザのデータを消すとレシピも消えます。設定画面の「データを消えにくくする」を押す、ホーム画面に追加して使う、ときどきバックアップする、のいずれかをおすすめします。
- 写真は保存時に自動で縮小（長辺2000px・JPEG）して容量を節約しています。
- iPhoneのHEIC写真はブラウザによって読み込めない場合があります。スクリーンショット（PNG）なら問題ありません。

## ファイル構成

```
index.html            画面の土台
styles.css            デザイン（ライト／ダークモード対応）
js/app.js             画面表示・操作（一覧／登録・編集／詳細／設定）
js/db.js              IndexedDB への保存
js/image.js           写真の縮小・サムネイル作成
js/ocr.js             文字読み取り（Tesseract.js を必要なときだけ読み込む）
js/recipe-text.js     分量の計算・投稿文の振り分け（DOMを使わない純粋な関数）
js/card.js            文章からカード画像を作る
js/ai.js              Claude API で写真・文章からレシピを書き起こす
js/importer.js        取り込みサーバーから写真と文章を取ってくる
server/import-worker.js  SNS取り込みサーバー（Cloudflare Workers）
tests/                テスト（node --test tests/*.test.mjs）
sw.js                 Service Worker（オフライン対応・共有の受け取り）
manifest.webmanifest  PWA設定（ホーム画面アイコン・共有ターゲット）
icons/                アプリアイコン
```
